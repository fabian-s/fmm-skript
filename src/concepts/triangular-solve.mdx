Ein lineares Gleichungssystem, dessen Matrix
:k[Dreiecksform]{#triangular-matrix} hat,
lässt sich ohne Elimination direkt lösen, sofern alle
Diagonaleinträge ungleich null sind, denn durch sie wird geteilt; genau dann
ist die Matrix regulär. Für ein oberes
Dreieckssystem $\bU\bx = \bb$ enthält die unterste
Gleichung nur eine einzige Unbekannte; lösen wir sie und arbeiten uns
nach oben, steuert jede Gleichung genau eine neue Unbekannte bei.
Dieser Durchlauf von unten nach oben heißt
*Rückwärtseinsetzen* oder *Rücksubstitution* (back substitution); der
spiegelbildliche Durchlauf von oben nach unten für ein unteres
Dreieckssystem $\bL\by = \bb$ heißt
*Vorwärtseinsetzen* oder *Vorwärtssubstitution* (forward substitution).

Das kostet etwa $n^2$ Operationen für
$n$ Unbekannte, eine Potenz von $n$ weniger als die
$\sim n^3/3$, die das
:k[Gaußsche Eliminationsverfahren]{#gaussian-elimination}
zum Faktorisieren einer vollen Matrix braucht. Darauf beruht die
Standardstrategie der numerischen linearen Algebra: die Matrix einmal in
Dreiecksfaktoren zerlegen (etwa
:k[LU]{#lu-decomposition} oder
:k[Cholesky]{#cholesky-factorization}), dann
jedes Lösen mit Einsetz-Durchläufen abschließen. Bei Kleinste-Quadrate-Problemen
endet etwa das QR-Verfahren mit Rückwärtseinsetzen in
$\bR\bx = \bc_1$ (vgl. Heath §3.4).
