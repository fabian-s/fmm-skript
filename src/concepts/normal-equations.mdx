Ein :k[lineares Kleinste-Quadrate-Problem]{#linear-least-squares}
minimiert die quadrierte Residuenlänge
$\phi(\bx) = \| \bb - \bA\bx \|_2^2$.
An ihrem Minimum muss der :k[Gradient]{#gradient}
verschwinden, bei uns ein Zeilenvektor:
$\nabla \phi(\bx) = 2(\bA\bx - \bb)^{T}\bA$.
Auf null gesetzt und transponiert sind das die
*Normalengleichungen* (engl. *normal equations*):

$$
\bA^{T} \bA \, \bx = \bA^{T} \bb,
$$

ein quadratisches $n \times n$-System, obwohl
$\bA$ selbst hoch und schmal ist. Der Name kommt aus der
Geometrie: Mit dem Residuum $\br = \bb - \bA\bx$ lautet es
$\bA^{T}\br = \bzero$, also steht $\br$
:k[orthogonal]{#orthogonality} („normal“) auf
jeder Spalte von $\bA$. Das beste
$\bA\bx$ ist der Fußpunkt des Lots von
$\bb$ auf den :k[Spann]{#span} der
Spalten.

Die Matrix $\bA^{T}\bA$ ist
:k[symmetrisch]{#symmetric-matrix} und
:k[positiv definit]{#positive-definite},
sobald die Spalten von $\bA$
:k[linear unabhängig]{#linear-independence}
sind; die
:k[Cholesky-Zerlegung]{#cholesky-factorization}
löst das System dann effizient. Allerdings ist die
:k[Konditionszahl]{#condition-number} von
$\bA^{T}\bA$ das *Quadrat* von
$\operatorname{cond}(\bA)$: Das Aufstellen von
$\bA^{T}\bA$ kann
:k[Rundungsfehler]{#rounding-error} kräftig
verstärken, eine
:k[QR-Zerlegung]{#qr-factorization} von
$\bA$ vermeidet das.
