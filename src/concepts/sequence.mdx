Eine Folge (sequence) ist eine unendliche, *geordnete* Liste von
Zahlen

$$
a_1,\; a_2,\; a_3,\; a_4,\; \dots,
$$

kurz $(a_n)_{n \in \N}$; $a_n$ heißt das $n$-te Glied. Formal ist eine Folge eine
:k[Funktion]{#function}, die jedem Index $n$ eine Zahl $a_n$
zuordnet; wir zählen ab $n = 1$. Die Reihenfolge gehört dazu: Die Liste
$1, \tfrac{1}{2}, \tfrac{1}{3}, \dots$ (also
$a_n = 1/n$) ist eine andere Folge als dieselben Zahlen in
durchgewürfelter Reihenfolge.

Auf Folgen beruht der Begriff der
:k[Konvergenz]{#convergence}: Viele Folgen nähern sich mit wachsendem $n$
einem festen Wert. Für $a_n = 1/n$ ist er $0$: Zu jedem
$\varepsilon > 0$ ist $1/n < \varepsilon$, sobald $n > 1/\varepsilon$. Und
summieren wir die Glieder einer Folge nacheinander auf, entsteht eine
:k[unendliche Reihe]{#infinite-series}.

Wie hält ein Punktbild von $a_n = 1/n$ die Reihenfolge der Glieder fest?

Jedes Glied steht über seinem Index, $a_1 = 1$ links, $a_{20} = 0{,}05$
rechts. So bleibt die Reihenfolge erkennbar, auch wenn die Werte immer
dichter an die Grenzlinie $0$ rücken.
