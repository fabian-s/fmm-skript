Eine Folge (sequence) ist eine unendliche, *geordnete* Liste von
Zahlen

$$
a_0,\; a_1,\; a_2,\; a_3,\; \dots,
$$

wobei der Index die Position angibt: $a_0$ ist das erste
Glied, $a_{17}$ das achtzehnte, und es gibt immer ein
nächstes. Formal ist eine Folge einfach eine
:k[Funktion]{#function}, die jedem Index
$n \in \N$ eine Zahl $a_n$ zuordnet. Die
Reihenfolge zählt: Die Liste
$1, \tfrac{1}{2}, \tfrac{1}{3}, \dots$ (also
$a_n = 1/n$) ist eine andere Folge als dieselben Zahlen in
durchgewürfelter Reihenfolge.

Folgen sind das Grundwerkzeug hinter der
:k[Konvergenz]{#convergence}: Viele Folgen
pendeln sich mit wachsendem $n$ auf einen festen Wert ein:
$a_n = 1/n$ strebt gegen $0$, wie die Punkte unten
zeigen. Und summieren wir die Glieder einer Folge nacheinander auf,
entsteht eine
:k[unendliche Reihe]{#infinite-series}.
